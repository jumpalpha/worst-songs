How to install

🍎 iPhone / iPad
  1. Open worstsong.com in Safari (newer iPhones: Chrome works too).
  2. Tap the Share button (the square with the arrow up).
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add. Done. Look for the yellow icon.
🤖 Android
  1. Open worstsong.com in Chrome.
  2. Tap Install the app above, or the ⋮ menu → Install app (or Add to Home screen).
  3. Tap Install. That's it.
💻 Computer
  1. In Chrome or Edge, click the little install icon at the right end of the address bar.
  2. Click Install. It opens in its own window, like a real app.
